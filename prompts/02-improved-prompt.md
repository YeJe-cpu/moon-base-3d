# 改进版提示词（约 600 字，未实测）

> 根据 7 轮迭代的经验反推：把参考作品里「提示词没写、但效果靠它」的构图、界面、舱内视角写进文字。

用 three.js 做一个单文件、可拖拽旋转缩放的 3D 桌面沙盘：「月面建设工地与开发中心」。所有模型都用代码生成。

【主角与布局】方形厚底座，侧面是月壤分层，前沿用立体字写「SELENE // SITE 07」。中心是半埋的穹顶开发中心：上半部是分格玻璃天窗，透出暖光；正前方接白色前厅舱，有整面落地窗、带圆舷窗的双道气闸门和门前台阶。左边：带橙色环带的圆柱舱、挂着宇航服的玻璃通廊、金箔着陆器和着陆垫。后方：黄色龙门吊、天线、闪烁的障碍灯。右边：未完工的 3D 打印穹顶，配橙色机械臂和传送带；右前停一艘三角翼飞船。前景：六轮月球车、充电桩、照明杆在入口投下光池。元素紧凑密集，不留大片空地。

【界面】左上：标题。右上：实时环境面板（时间、内外温度、O₂、电力）。3D 区域标签带引线、跟随物体移动。侧边视角按钮：全景 / 入口 / 打印区 / 舱内，点击后镜头平滑飞过去。

【舱内】点「舱内」，镜头飞进穹顶：暖色明亮的控制室，一排发光监控屏（图表、雷达），工作台和座椅，天花板下悬浮环形光圈和蓝色全息地球，还有休息区和植物舱。这是全作的高光。

【光与色】月夜无大气，纯黑星空不闪。冷蓝探照灯照出地面光池，舱内暖光透窗，橙色只做点缀。深灰月壤，白色舱体要有明暗层次。用 sRGB + ACES + OutputPass，bloom 只给小灯点，不要大面积过曝和光雾。

【镜头】俯角约 28°，底座占画面 75~80%，完整不裁切，慢速自动环绕。

不要人物。像素比开到 2，不要自动降画质。
